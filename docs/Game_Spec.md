## 1. 初期状態と基本ルール

| 仕様 | 状況 | 内容 |
|---|---|---|
| 更地からのスタート | ✅ | ゲーム開始時は建物が一切なく、1階を示す地面の線と、空・地下（土）だけが広がる状態から始まる |
| ビルの大きさの上限 | ✅ | 地上150階・地下50階（合計200階）、横100マスまで | `main.gd` の `MAX_FLOORS_ABOVE`・`MAX_FLOORS_BELOW`・`MAX_WIDTH`。`get_size_limit_problem()` で、建てる前に判定する |
| 建物の支え | ✅ | 建物は下の階に建物がないと建てられない（空中に浮いた建物は作れない）。地下は上の階に建物がないと掘れない。ほかの建物を支えている建物は撤去できない（上の階から＝地下は下の階から撤去する） |
| 1階の建築制約 | ✅ | 1階にはオフィスや住宅などのテナントを建てられない。1階は「1階メインロビー」専用のフロアとして使う（ロビーのほか、上下の階とつなぐ階段・エレベーターは置ける） |

- 1階の高さ（y座標）は `scripts/main.gd` の `GROUND_FLOOR_Y` で固定する。それより下が地下。
- 建てられる階の制限は、`BUILDINGS` の各建物の `"floors"` で決める（`"ground"`: 1階だけ、`"basement"`: 地下だけ、`"any"`: どこでも、`"sky_lobby"`: 15階ごとの階だけ、省略: 1階以外）。
- 建物の支えは `get_support_problem()`（建設）と `get_demolish_problem()`（撤去）で判定する。地上は一番下の階の全部のマスの真下、地下は一番上の階の全部のマスの真上に建物が必要。
- 人はロビーの左端（1階の入口）から出入りするので、まずロビーを建てないと誰もビルに来ない。

## 2. 交通・インフラ系（動線・ボトルネックの要）

| 施設 | 状況 | 仕様 | 今の実装・方針 |
|---|---|---|---|
| 1階メインロビー | ✅ | すべての人が外から入ってくるビル全体の土台となる巨大な入口。横幅を自由に拡張でき、上階の床を抜いて吹き抜けにもできる | 1階専用の建物 `lobby`（1マスずつ建てて横に伸ばせる）と、高さのある吹き抜けロビー `lobby2`・`lobby3`（`"height"` で2〜3階分。人が歩けるのは一番下の階だけ） |
| スカイロビー（空中ロビー） | ✅ | 15階、30階、45階など、15階刻みでしか建設できない乗り換え専用フロア | `"floors": "sky_lobby"`（15階ごとの階だけ）の建物 `sky_lobby`。歩いて乗り換えられるが、入口にはならない |
| 急行エレベーター | ✅ | 1階とスカイロビーのみをつなぐ大型高速エレベーター。ここから各階用の標準エレベーターに乗り換えさせる | シャフトの種類 `express_elevator`（`elevator_system.SHAFT_TYPES`）。`get_moves()` は1階とスカイロビーの階どうしの移動だけを作り、途中の階では乗り降りできない。カゴは標準の3倍の速さ・定員20人・金色 |
| 階段 | ✅ | 1〜2階層の移動用。維持費なし | 実装済み（移動コストで近い階だけ使われる） |
| エスカレーター | ✅ | 商業施設エリア（映画館や店舗）の大量輸送向け。エレベーターの負担を減らす | 横2マスの建物 `escalator`。左のマス（乗り口）と1つ上の階の右のマス（降り口）を斜めにつなぐ（上り下りとも）。移動コストは1階分 1.0（階段 2.0）で、定員・待ち時間なし。維持費 2,000円/日 |
| 標準エレベーター | ✅ | 一般的な昇降機。待機階（ホーム）の設定や、稼働時間帯の指定による運行ダイヤ調整が可能 | 定員・複数カゴ・集合制御・群管理に加えて、シャフトごとの待機階（`elevator_system.home_floors`）と稼働時間帯（`service_hours`。終日／6時〜24時／8時〜20時）を実装。時間帯の外では呼べず、経路にも使われず、カゴは待機階に戻る |
| サービスエレベーター | ✅ | 清掃員（ハウスキーパー）と警備員専用の裏方動線。一般客は乗れない | シャフトの種類 `service_elevator`。`get_moves()`・`find_path()` に「裏方かどうか（`staff`）」を渡し、裏方だけ乗れるようにした。今の裏方は清掃員（警備員はまだ人として登場しない） |
| 地下駐車場・スロープ | ✅ | 商業施設や映画館の集客力を上げるための必須インフラ | 地下専用の `parking`（横4マス・4台）と `ramp`（横2マス）。スロープは地下のどの階にも建てられ、地下1階から途切れずに続いている（`connected_ramps()`）ものだけ車が下りてこられる。駐車場は同じ階のスロープまで行けるときだけ使え、`parking_system` が台数×2人の来客を昼に呼ぶ。行き先は飲食店とショップ。さらに、映画館の1回の客が台数ぶん増える |
| 地下鉄駅 | ✅ | 地下深く（B10階など）に設置することで、1階エントランス以外からの巨大な人員流入ゲートとなる | 地下5階（`main.SUBWAY_MIN_DEPTH`）より深いところにだけ建てられる2つ目の入口。駅1つにつき、店・映画館へ来る外からのお客さんが+50%（最大2倍。`visitor_system.subway_rate()`） |

## 3. テナント・施設系（資金源とノイズ源）

| 施設 | 状況 | 仕様 | 今の実装・方針 |
|---|---|---|---|
| オフィス | ✅ | 平日の昼間に人が活動。夜と休日は無人になる安定した資金源 | 実装済み（評価・退去も実装中） |
| マンション/住宅 | ✅ | 買い切りでの多額の資金（分譲）。周囲の「騒音（ノイズ）」に極めて敏感 | 分譲・評価・退去に加えて、騒音の影響も実装（下の「騒音」を参照） |
| ホテル（シングル/ツイン/スイート） | ✅ | 夜間にチェックインし、朝にチェックアウト。清掃員の配置が必須 | 実装済み |
| オフィスの種類 | ✅ | 区画の大きさを選べるようにして、狭い場所の使い道と、まとめ借りの得を作る | `small_office`（横2マス・24万円・2人・賃料11,000円/マス）と `large_office`（横6マス・48万円・6人・9,000円/マス）を追加。賃料は `economy_system.OFFICE_RENTS` に種類ごとに持つ |
| 空きフロア（撤去の跡地） | ✅ | 上の階を崩さずに低い階のテナントを入れ替えられるようにする | `frame`（建設費0・横1マス。メニューには出さない）。上（地下なら下）の階を支えているマスを撤去すると、建物の代わりに `frame` を置く。`frame` は通り抜けでき（1マスなので `is_walkable`）、`is_buildable_cell()` で空マスと同じように上書き建設できる。跡地そのものは、支えている間は撤去できない |
| 店舗・ファストフード | ✅ | 昼食時や休日に外部からの来客（非居住者）を呼ぶ。配置しすぎるとエレベーターがパンクする | 飲食店（社員の昼食）に加えて、`shop`（ショップ。横3マス）、`fastfood`（ファストフード。横2マス・12万円。食事10分・600円）と `visitor_system` を実装。入口から来る外の客が、平日は昼（飲食店2人・ファストフード3人・ショップ3人）、休日は昼から夕方（8人・10人・10人）に店へ来る。車で来た客（`parking_system`）も同じ仕組みで動く |
| 映画館 | ✅ | 上下に複数階をぶち抜く大型施設。上映時間に客が一斉に来て一斉に帰る強烈なスパイクを生む | 横8マス・高さ2階分の `cinema`。`visitor_system.CINEMA` が上映時刻（平日3回・休日4回、1回2時間）を持ち、30分前から客が集まって終映で一斉に帰る。料金1,800円。使える駐車場の台数だけ客が増える（最大8人） |
| リサイクルセンター | ✅ | 各テナントのゴミを処理する。許容量を超えると環境悪化の原因になる | 処理能力・外部委託費に加えて、衛生の悪化を実装（`economy_system.pollution`: あふれたゴミ5につきレベル1、上限5。レベル1につきストレス5相当が全テナントの評価に足され、足りた日は1レベルずつ戻る）。衛生の悪化が続くとゴキブリが発生する（Phase 12 で実装） |
| メディカルセンター | ✅ | 住民の健康状態（ストレス）を緩和する | ★3の条件に加えて、ストレスの回復を速める効果を実装（`main.stress_recover_rate()`: 1施設ごとに+50%、上限2.5倍。ビル全体に効く） |
| 警備室 | ✅ | 犯罪イベントの回避や火災対応に必要 | ★2の条件に加えて、警備員の常駐・爆弾の解体・消火を実装 |

### 騒音（ノイズ）✅
- `noise_system.gd` が、うるさい建物（`NOISE_SOURCES`: 映画館5・イベントホール5・結婚式場4・ゴミ処理場4・地下鉄駅4・飲食店3・ファストフード3・急行エレベーター3・駐車場3・ショップ2・エレベーター2・エスカレーター2・ロビー2）から、距離1につき1ずつ弱めながら騒音を広げ、マスごとの値を `noise_map` に持つ（重なりは足し算、1マス最大10）。
- 住宅・ホテルの客室は、`NOISE_TOLERANCE`（1）を超えた騒音1につきストレス6相当を評価に足す（`tenant_system`）。静かな場所に住宅を置くことが大事になる。
- カーソルを合わせると「静か」「騒音 4（うるさい）」のように出る。

## 4. イベント・トラブル系（進行とランダム要素）

| イベント | 状況 | 仕様 |
|---|---|---|
| VIPの宿泊（★昇格イベント） | ✅ | 次の★へ昇格するための最終試験。VIPが来館してスイートに泊まる。入口からスイートまでの移動で待たせないこと、部屋が清潔であることがクリア条件。`vip_system.gd`: ★4の条件（人口250・地下鉄駅）がそろうと16時に来館し、ストレス30以下できれいな空きスイートに着けば合格。不合格なら翌日また来る |
| 爆破予告（テロ） | ✅ | テロリストから身代金要求が届く。時間内に警備員が爆弾を見つけて解体できないとテナントが吹き飛ぶ。`incident_system.gd`: ★2以上のビルに1日15%の確率で10時に予告（制限120分）。警備室1つにつき警備員1人が常駐し、一番近い警備員が現場で10分かけて解体する。失敗するとそのテナントが消える（払い戻しなし） |
| 火災 | ✅ | ランダムに発生し、周囲に延焼する。ヘリポートからの消火ヘリや警備員の急行で鎮火する。`incident_system.gd`: ★2以上のビルに1日10%の確率で20時に出火。20分ごとに隣（左右）と上へ延焼し、1マスが60分燃えるとそのテナントが焼け落ちる。警備員が現場で10分かけて1マスずつ消す。屋上に `helipad`（横4マス）を建てると消防ヘリが飛んできて、上の階の火から5分で1マスずつ消す |
| テナントの激怒と退去 | ✅ | エレベーターの待ち時間が長すぎる・騒音がひどいなどでストレスが限界を超えると、赤く点滅し、最後には退去する。人はストレス95以上で顔が赤く点滅（`resident.is_angry()`）、退去まであと1日のテナントは評価のマークが点滅（`tenant_system.is_about_to_leave()`）。人数・件数は上部バーにも出る |
| 埋蔵金の発見 | ✅ | 地下へ採掘を進めると、ランダムで財宝を掘り当てて臨時収入が得られる。`incident_system.gd`: 地下に建てたマスごとに判定（地下1階3%、1階深くなるごとに+0.2%、上限12%）。金額は深さ1階につき1〜2万円（上限100万円）。同じマスは一度きり |
| ゴキブリ大繁殖 | ✅ | ゴミの未回収や衛生状態の悪化が続くと発生。テナントの評価が激減する。`incident_system.gd`: 衛生の悪化レベル4以上が2日続くと発生し、毎日3棟ずつ広がる。いるテナントは評価にストレス15相当が足され、悪化が0に戻るといなくなる |
| サンタクロースの飛来 | ✅ | 12月24日・25日ごろの夜空を、ソリが横切るフレーバーイベント（日付に月・日を導入する）。`game_clock.gd` にカレンダー（1日目＝4月1日、1年365日）を追加し、12月24日・25日の21時〜24時にソリが空を左から右へ横切る |
| 雨・天候変化 | ✅ | 天候が悪化すると、屋上施設や客足に影響が出る。`weather_system.gd`: 日付から決まる晴れ（約6割）・くもり・雨。6月は梅雨で雨が多い。雨の日は入口から来る店の客が半分になり（車で来る客は減らない）、空が暗くなって雨が降る |

- イベントは `incident_system.gd` にまとめる（今の `event_system.gd` は結婚式場・イベントホールの来客）。爆破予告は実装済み。
- 毎日の決算か、決まった時刻に発生を判定する。ランダムは日付から作る乱数で決め、テストで再現できるようにする。

### バランス ✅
- `tools/balance_check.gd` で、自動で遊ぶ計測ができる（`godot --path . -s res://tools/balance_check.gd -- 30`）。毎日の資金・人口・★・退去・目標を表にする。
- 計測の結果で調整したこと: ロビー 3万→1.5万円/マス、エレベーター 10万→8万円/マス（序盤の負担を軽く）、
  目標の期限を 30/60/90日 → 45/90/120日、テナントの退去は1日2棟まで（一度に全部出ていかないように）。

### はじめての案内 ✅
- `tutorial_system.gd` の `STEPS` を順に出す。各ステップは `is_step_done()` で達成を判定し、満たすと次へ進む。
- 上部バーの下に1行で出し、「案内を閉じる」でいつでもやめられる。進み具合はセーブに含める。

### 目標（シナリオ）✅
- `goal_system.gd` の `GOALS` に、順に挑戦する目標（★・資金・人口・期限）を並べる。毎日の決算のあとに達成を判定する。
- 達成したら `main.show_goal_panel()` で知らせて次の目標へ。全部達成でクリア。期限を過ぎても続けられる（遅れて達成してもよい）。
- 今の目標は上部バーに出し、進み具合はセーブに含める。

### タイトル画面 ✅
- 起動すると `main.create_title()` のタイトル画面が出る（「はじめから」「続きから」）。始まるまでは時計を止め、マップの操作も受け付けない。
- 「続きから」は、セーブデータがあるときだけ押せる（`save_system.has_save()`）。

### 配布 ✅
- `export_presets.cfg` に macOS と Windows の設定を置く（`docs/`・`tools/`・`tests/` は除外）。書き出し先は `build/`（gitignore 済み）。
- `icon.svg` はビルの絵。`project.godot` に説明とバージョンを入れてある。
- 書き出しにはエクスポートテンプレート（Godot エディタからダウンロード）が必要。

### 屋上庭園 ✅
- 屋上（`"floors": "rooftop"`）に建てる `garden`（横4マス）。ビル全体のストレスの回復が1つにつき+30%（メディカルセンターと合わせて上限2.5倍）。
- `noise_system.quiet_bonus()` で、ビル全体の騒音を1つにつき3ぶん和らげる。

### 見た目の演出 ✅
- 人は歩くときに足の形を切り替える（`resident.WALK_LEGS` と進んだ距離 `walked`）。
- `effects.gd` が、建設（白い枠）・撤去（土ぼこり）・黒字の決算（「+◯◯円」の文字）の短い演出を描く。

### 音 ✅
- `audio_system.gd` が、効果音（建設・撤去・チャイム・決算・警報・ブザー）とBGMを、`AudioStreamWAV` の波形としてコードで作る（音源ファイルは持たない）。
- BGMは和音のくり返しで、昼と夜で和音が変わる。M キーで音のオン・オフ。
- 同じ効果音は `COOLDOWN` 秒に1回までにして、鳴らしすぎないようにしている。

### 遊びやすさ ✅
- ドラッグ（ボタンを押したままなぞる）で、続けて建設・撤去できる（`main.click_cell()` と `drag_button`）。
- 建設メニューの「撤去」（`MODE_DEMOLISH`）を選ぶと、左クリックで撤去できる。
- ⌘G で収支のグラフ（`chart_view.gd`）。`economy_system.history` に決算を60日ぶん残し、棒グラフと内わけで見せる。

### セーブ／ロード ✅
- `save_system.gd` が、ビルの状態を JSON（`user://save.json`）に保存し、読み込んで元に戻す（⌘S / ⌘O）。
- 保存するもの: 建物の配置（左端のマスと種類）・資金・日付と時刻・★・VIPの合否・エレベーターの設定（カゴ・待機階・稼働時間帯）・テナントの評価・客室と住宅の状態・衛生の悪化・ゴキブリ・掘った地下のマス。
- 人（住人）は保存せず、読み込み後に各システムが出し直す。`main.place_unit()` / `main.clear_world()` を使って建物を組み直す。

## 5. データ構造の方針

今の実装のデータ構造を、次のように広げて対応します。

| 今のデータ構造 | 広げ方 |
|---|---|
| `BUILDINGS`（種類・建設費・横幅） | `"floors"`（建てられる階）と `"height"`（縦の階数）は実装済み。`"noise"`（騒音）などを足す |
| `building_grid`（マス → 種類と左下のマス） | 縦にも広がる建物は左下のマスを基準（origin）にし、`get_footprint()` は横幅×高さ（実装済み）。人が歩けるのは建物の一番下の階だけ（`is_walkable()`） |
| `get_moves()`（移動ルールとコスト） | エスカレーター・急行・サービスエレベーターの移動を実装済み。人の種類（`staff`）で乗れる移動を絞る |
| `elevator_system`（シャフトとカゴ） | シャフトに種類（標準・急行・サービス）を持たせる。設定（待機階・稼働時間帯）はシャフトごとに実装済み |
| `tenant_system`（評価・退去） | 騒音・衛生などの要素を評価に加える。赤い点滅の表示を足す |
| `game_clock`（日・曜日・時刻） | 月・日（カレンダー）と天候を足す |
| 各 `*_system.gd` | イベントは `incident_system.gd`、騒音は `noise_system.gd` のように仕組みごとにファイルを分ける |
