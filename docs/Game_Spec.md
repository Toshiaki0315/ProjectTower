## 1. 初期状態と基本ルール

| 仕様 | 状況 | 内容 |
|---|---|---|
| 更地からのスタート | ✅ | ゲーム開始時は建物が一切なく、1階を示す地面の線と、空・地下（土）だけが広がる状態から始まる |
| 建物の支え | ✅ | 建物は下の階に建物がないと建てられない（空中に浮いた建物は作れない）。地下は上の階に建物がないと掘れない。ほかの建物を支えている建物は撤去できない（上の階から＝地下は下の階から撤去する） |
| 1階の建築制約 | ✅ | 1階にはオフィスや住宅などのテナントを建てられない。1階は「1階メインロビー」専用のフロアとして使う（ロビーのほか、上下の階とつなぐ階段・エレベーターは置ける） |

- 1階の高さ（y座標）は `scripts/main.gd` の `GROUND_FLOOR_Y` で固定する。それより下が地下。
- 建てられる階の制限は、`BUILDINGS` の各建物の `"floors"` で決める（`"ground"`: 1階だけ、`"basement"`: 地下だけ、`"any"`: どこでも、`"sky_lobby"`: 15階ごとの階だけ、省略: 1階以外）。
- 建物の支えは `get_support_problem()`（建設）と `get_demolish_problem()`（撤去）で判定する。地上は一番下の階の全部のマスの真下、地下は一番上の階の全部のマスの真上に建物が必要。
- 人はロビーの左端（1階の入口）から出入りするので、まずロビーを建てないと誰もビルに来ない。

## 2. 交通・インフラ系（動線・ボトルネックの要）

| 施設 | 状況 | 仕様 | 今の実装・方針 |
|---|---|---|---|
| 1階メインロビー | ✅ | すべての人が外から入ってくるビル全体の土台となる巨大な入口。横幅を自由に拡張でき、上階の床を抜いて吹き抜けにもできる | 1階専用の建物 `lobby`（1マスずつ建てて横に伸ばせる）と、高さのある吹き抜けロビー `lobby2`・`lobby3`（`"height"` で2〜3階分。人が歩けるのは一番下の階だけ） |
| スカイロビー（空中ロビー） | ✅ | 15階、30階、45階など、15階刻みでしか建設できない乗り換え専用フロア | `"floors": "sky_lobby"`（15階ごとの階だけ）の建物 `sky_lobby`。歩いて乗り換えられるが、入口にはならない |
| 急行エレベーター | ✅ | 1階とスカイロビーのみをつなぐ大型高速エレベーター。ここから各階用の標準エレベーターに乗り換えさせる | シャフトの種類 `express_elevator`（`elevator_system.SHAFT_TYPES`）。`get_moves()` は1階とスカイロビーの階どうしの移動だけを作り、途中の階では乗り降りできない。カゴは標準の3倍の速さ・定員20人・金色 |
| 階段 | ✅ | 1〜2階層の移動用。維持費なし | 実装済み（移動コストで近い階だけ使われる） |
| エスカレーター | ✅ | 商業施設エリア（映画館や店舗）の大量輸送向け。エレベーターの負担を減らす | 横2マスの建物 `escalator`。左のマス（乗り口）と1つ上の階の右のマス（降り口）を斜めにつなぐ（上り下りとも）。移動コストは1階分 1.0（階段 2.0）で、定員・待ち時間なし。維持費 2,000円/日 |
| 標準エレベーター | ✅ | 一般的な昇降機。待機階（ホーム）の設定や、稼働時間帯の指定による運行ダイヤ調整が可能 | 定員・複数カゴ・集合制御・群管理に加えて、シャフトごとの待機階（`elevator_system.home_floors`）と稼働時間帯（`service_hours`。終日／6時〜24時／8時〜20時）を実装。時間帯の外では呼べず、経路にも使われず、カゴは待機階に戻る |
| サービスエレベーター | ✅ | 清掃員（ハウスキーパー）と警備員専用の裏方動線。一般客は乗れない | シャフトの種類 `service_elevator`。`get_moves()`・`find_path()` に「裏方かどうか（`staff`）」を渡し、裏方だけ乗れるようにした。今の裏方は清掃員（警備員はまだ人として登場しない） |
| 地下駐車場・スロープ | 🔶 | 商業施設や映画館の集客力を上げるための必須インフラ | 地下専用の `parking`（横4マス・4台）と、地下1階専用の `ramp`（横2マス）。スロープまで車で行ける駐車場だけが使え、`parking_system` が台数×2人の来客を昼に呼ぶ。今の行き先は飲食店だけ（店舗・映画館は Phase 11） |
| 地下鉄駅 | ✅ | 地下深く（B10階など）に設置することで、1階エントランス以外からの巨大な人員流入ゲートとなる | 地下専用・2つ目の入口として実装済み。深さの条件（B10階など）と、駅からの外部客の流入は ⬜ |

## 3. テナント・施設系（資金源とノイズ源）

| 施設 | 状況 | 仕様 | 今の実装・方針 |
|---|---|---|---|
| オフィス | ✅ | 平日の昼間に人が活動。夜と休日は無人になる安定した資金源 | 実装済み（評価・退去も実装中） |
| マンション/住宅 | 🔶 | 買い切りでの多額の資金（分譲）。周囲の「騒音（ノイズ）」に極めて敏感 | 分譲は実装済み。騒音は ⬜（下の「騒音」を参照） |
| ホテル（シングル/ツイン/スイート） | ✅ | 夜間にチェックインし、朝にチェックアウト。清掃員の配置が必須 | 実装済み |
| 店舗・ファストフード | 🔶 | 昼食時や休日に外部からの来客（非居住者）を呼ぶ。配置しすぎるとエレベーターがパンクする | 飲食店（社員の昼食）は実装済み。外部からの来客と休日の営業は ⬜ |
| 映画館 | ⬜ | 上下に複数階をぶち抜く大型施設。上映時間に客が一斉に来て一斉に帰る強烈なスパイクを生む | 高さのある建物（`"height": 2` など）。上映時刻に合わせて来客を一斉に出す（今のイベントホールの仕組みを流用） |
| リサイクルセンター | 🔶 | 各テナントのゴミを処理する。許容量を超えると環境悪化の原因になる | 処理能力と外部委託費は実装済み。許容量を超えたときの環境悪化（評価の低下・ゴキブリ）は ⬜ |
| メディカルセンター | 🔶 | 住民の健康状態（ストレス）を緩和する | ★3の条件としては実装済み。ストレスの回復を早める効果は ⬜ |
| 警備室 | 🔶 | 犯罪イベントの回避や火災対応に必要 | ★2の条件としては実装済み。テロ・火災への対応は ⬜ |

### 騒音（ノイズ）⬜
- 飲食店・映画館・エレベーター・ロビーなどを「騒音を出す建物」とし、近くのマスに騒音を広げる（マスごとの騒音の値を `noise_map` に持つ）。
- 住宅・ホテルなど騒音に敏感なテナントは、騒音の大きさを評価に加える（`tenant_system` の評価の仕組みを流用）。

## 4. イベント・トラブル系（進行とランダム要素）

| イベント | 状況 | 仕様 |
|---|---|---|
| VIPの宿泊（★昇格イベント） | ⬜ | 次の★へ昇格するための最終試験。VIPが来館してスイートに泊まる。入口からスイートまでの移動で待たせないこと、部屋が清潔であることがクリア条件 |
| 爆破予告（テロ） | ⬜ | テロリストから身代金要求が届く。時間内に警備員が爆弾を見つけて解体できないとテナントが吹き飛ぶ |
| 火災 | ⬜ | ランダムに発生し、周囲に延焼する。ヘリポートからの消火ヘリや警備員の急行で鎮火する |
| テナントの激怒と退去 | 🔶 | エレベーターの待ち時間が長すぎる・騒音がひどいなどでストレスが限界を超えると、赤く点滅し、最後には退去する。（ストレスの色、オフィス・客室・住宅の評価、オフィス・住宅の退去は実装済み。赤い点滅と騒音は ⬜） |
| 埋蔵金の発見 | ⬜ | 地下へ採掘を進めると、ランダムで財宝を掘り当てて臨時収入が得られる |
| ゴキブリ大繁殖 | ⬜ | ゴミの未回収や衛生状態の悪化が続くと発生。テナントの評価が激減する |
| サンタクロースの飛来 | ⬜ | 12月24日・25日ごろの夜空を、ソリが横切るフレーバーイベント（日付に月・日を導入する） |
| 雨・天候変化 | ⬜ | 天候が悪化すると、屋上施設や客足に影響が出る |

- イベントは新しい `incident_system.gd` にまとめる（今の `event_system.gd` は結婚式場・イベントホールの来客）。
- 毎日の決算か、決まった時刻に発生を判定する。ランダムは日付から作る乱数で決め、テストで再現できるようにする。

## 5. データ構造の方針

今の実装のデータ構造を、次のように広げて対応します。

| 今のデータ構造 | 広げ方 |
|---|---|
| `BUILDINGS`（種類・建設費・横幅） | `"floors"`（建てられる階）と `"height"`（縦の階数）は実装済み。`"noise"`（騒音）などを足す |
| `building_grid`（マス → 種類と左下のマス） | 縦にも広がる建物は左下のマスを基準（origin）にし、`get_footprint()` は横幅×高さ（実装済み）。人が歩けるのは建物の一番下の階だけ（`is_walkable()`） |
| `get_moves()`（移動ルールとコスト） | エスカレーター・急行・サービスエレベーターの移動を実装済み。人の種類（`staff`）で乗れる移動を絞る |
| `elevator_system`（シャフトとカゴ） | シャフトに種類（標準・急行・サービス）を持たせる。設定（待機階・稼働時間帯）はシャフトごとに実装済み |
| `tenant_system`（評価・退去） | 騒音・衛生などの要素を評価に加える。赤い点滅の表示を足す |
| `game_clock`（日・曜日・時刻） | 月・日（カレンダー）と天候を足す |
| 各 `*_system.gd` | イベントは `incident_system.gd`、騒音は `noise_system.gd` のように仕組みごとにファイルを分ける |
