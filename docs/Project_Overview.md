# ProjectTower - Overview

## コンセプト
エレベーター群管理と住人のストレス管理を主軸に置いた2Dビル経営シミュレーション。

## コアシステム
- グリッドベースの2Dサイドビュー
- エレベーターの群管理AI（経路探索、待ち時間、ストレス計算）
- テナント経営（資金、賃料売上、維持費）
- 時間経過（1日のサイクル、平日・休日ごとの人の流れ）

## 登場アイテム
- **交通:** 通常/特大/サービスエレベーター、スカイロビー、エスカレータ、階段、地下鉄駅
- **テナント:** オフィス、住宅、ホテル（単発/ツイン/スイート）、商業施設、レストラン、結婚式場、宴会場、イベントホール
- **インフラ:** ハウスキーパー室、警備室、メディカルセンター、ゴミ処理場
